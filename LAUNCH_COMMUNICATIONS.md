# Launch Communications Plan

## Before launch

Notify approved stakeholders of:

```text
release date/time
expected maintenance/user impact
support contact
known accepted MINOR/LOW issues
status channel/location
```

## During launch

Use one authoritative status channel for:

```text
start
migration phase
application rollout
verification
incident/abort
completion
```

Avoid sharing secrets, internal tokens, or personal data in status messages.

## After launch

Communicate:

```text
release completed
service status
known issues
support route
next monitoring checkpoint
```

If launch is aborted, state:

```text
service impact
current safe state
next decision time
```

without speculating on unverified root cause.
